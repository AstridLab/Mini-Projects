# Patient Demographics and Hospital Trends

## Overview
This project analyzes hospital admission data to explore patient demographics and admission trends. Using data analysis and visualizations, it investigates age distribution, monthly admission patterns, and differences across admission types.

## Folder Structure
- `code/` : Jupyter notebooks and scripts for data cleaning, exploration, and visualization.  
- `dataset/` : Raw hospital dataset (`healthcare_dataset.csv`).  
- `results/` : Plots and summary tables generated from the analysis.

## Mini Conclusion
- Patient ages span all groups, with most patients in middle-age ranges.  
- Monthly admissions show seasonal and operational fluctuations.  
- Emergency and elective admissions follow distinct trends over time.  
- The insights can guide further analyses, such as predicting patient load or studying outcomes.

## How to Run
1. Open the notebook in the `code/` folder.  
2. Ensure `healthcare_dataset.csv` is in the `dataset/` folder.  
3. Run the notebook to reproduce the plots and results in the `results/` folder.
