# Cancer Predictive Modeling

## Overview
This project uses patient features to predict potential cancer diagnosis. The dataset contains 1,500 samples with features including Age, Gender, BMI, Smoking, Genetic Risk, Physical Activity, Alcohol Intake, and Cancer History.

Machine learning models (Logistic Regression and Decision Tree) were trained and evaluated to predict cancer status.

## Goals
- Preprocess and clean the patient dataset.
- Train classification models to predict cancer diagnosis.
- Evaluate model performance using accuracy, confusion matrix, and classification reports.

## Tools
- Python (pandas, numpy, matplotlib, seaborn)
- scikit-learn (Logistic Regression, Decision Tree, train_test_split, StandardScaler)
- Data visualization with matplotlib and seaborn

## Results
- Logistic Regression and Decision Tree achieved reasonable accuracy (~87%).
- Confusion matrices and classification reports show balanced performance across classes.
- Models are ready for further hyperparameter tuning or feature importance analysis.

## Conclusion
The patient dataset has been successfully cleaned and split into training and testing sets. Machine learning models were able to capture patterns in the data and predict cancer status with reasonable accuracy. This project demonstrates the end-to-end workflow of preprocessing, modeling, evaluation, and visualization for biomedical data.
